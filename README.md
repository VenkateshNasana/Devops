# DevOps Command Center

A complete DevOps lifecycle management platform for developers, DevOps engineers, project managers, and administrators.

## Features
- **Projects & Teams:** Manage users, teams, and projects.
- **Repositories & Environments:** Integrate with VCS providers and manage environments.
- **CI/CD Pipelines:** Visual pipeline builder and execution engine.
- **Deployments:** Manage deployments, strategies, and rollbacks.
- **Monitoring & Logging:** Centralized logs and health checks.
- **Incident Management:** Full lifecycle incident tracking.
- **Notifications & Audit:** Event-based notifications and audit logging.

## Tech Stack
- **Frontend:** React, Vite, TypeScript, Tailwind CSS
- **Backend:** Python, Django, DRF, Celery
- **Database:** PostgreSQL, Redis
- **DevOps:** Docker, Docker Compose, Nginx, GitHub Actions
